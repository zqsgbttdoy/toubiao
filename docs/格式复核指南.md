# 附件格式复核指南（零基础版）

> 用途：配合「格式复核样例」文件夹里的 Word 文件，逐项核对每个附件模板生成的**版式格式**是否符合投标要求。
> 你不需要懂代码，照着下表打开文件、看对不对即可。发现异常按最后的「反馈模板」把编号发给我，我来改。

## 一、样例文件在哪、怎么打开

- 文件夹位置：`docs/格式复核样例_全量/`（共 48 份 Word，编号 01–48）
- 打开方式：用「文件资源管理器」进入该文件夹 → **双击任意文件**，用电脑上的 Word / WPS 打开
- 文件夹内 `_索引.txt` 是「编号 ↔ 模板名」对照表
- ⚠️ 重要：样例里的文字是**自动填的"示例"占位数据**，只看版式格式用；正式数据请在软件界面里录入后生成

## 二、按版式分 8 类的核对表

| 版式类 | 对应样例编号 | ✅ 正确应看到 | ❌ 有这些请告诉我 |


## 四、想重新生成全部样例（可选）

在项目文件夹地址栏输入 `powershell` 回车，再粘贴下面这行回车：

```
.venv\Scripts\python.exe -m tests.export_all_samples
```
