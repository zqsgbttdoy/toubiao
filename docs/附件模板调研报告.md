# 投标平台附件模板调研报告

> **通俗说明**：本报告把"附件"理解为投标书后面那一沓表格、承诺书、横道图、清单等。"渲染引擎"指的是软件里"把数据画成 Word 表格"的现成代码模块，能复用就省事，需要新写就费工。

---

## 一、现有系统能力速览

### 已实现的 docx 生成器（2 个）

| 模板 | 能力 | 适用场景 |
|------|------|---------|
| `personnel-gantt` | 横向A4，时间分桶（日/周/月自适应），单元格填色画横道 | 人员进出场横道图 |
| `equipment-list` | 竖向A4，6列固定表格，表头跨页重复 | 拟投入设备清单 |

### 可复用的底层工具（`docx_kit.py`）

8 个"积木"函数：新建文档、单元格填色、写入文本、固定列宽、表头重复、竖排文字、时间分桶、序列化输出。

### 已有 18 个文本模板

其中 **8 个已在正文里写了 Markdown 表格**（进退场登记表/机构组成表/业绩表/报价明细/偏离表/TIS检查节点/设备清单/风险清单），但**尚无对应的结构化 docx 生成器**——这是扩展的最大富矿。

## 三、引擎复用分析

### A. 甘特引擎（可直接改字段复用）

现有 `personnel-gantt` 的核心能力：时间分桶 + 单元格着色 + 横向A4 + 自动分页。

**可直接复用**（仅改字段名，每个约 0.5 人天）：

| 附件 | 字段映射 |
|------|---------|
| 施工进度计划横道图(#28) | name→工序名称, role→所属分部, entry→计划开始, exit→计划结束 |
| TIS检查横道图(#29) | name→检查节点, role→检查阶段, entry→计划开始, exit→计划结束 |
| 设备进退场横道图 | name→设备名称, role→型号, entry→进场, exit→退场 |
| 材料供应计划横道图 | name→材料名称, role→规格, entry→开始供应, exit→结束供应 |

**需小幅扩展**（约 1.5 人天）：
- 人月计划表(#27)：需在横道下方增加"每月在场人数"柱状行

### B. 列式引擎（可直接改列定义复用）

现有 `equipment-list` 的核心能力：固定列表格 + 表头着色 + 跨页重复 + 自动分页。

**可直接复用**（仅改 HEADERS + WIDTHS + Pydantic，每个约 0.3 人天）：

共 **24 项** 附件可直接复用，包括：商务偏离表、技术偏离表、风险识别清单、TIS检查节点计划表、人员证书一览表、开标一览表、办公设施表、旁站方案表、见证取样计划表、风险分级标准表、报告时效表、财务证明表、工作制度清单、实施细则清单、IDI分工表、材料计划表、临时用地表、分包情况表等。

**需小幅扩展**（每个约 0.5-1 人天）：
- 横向A4多列表（进退场登记表16列、业绩表19列）
- 计算列（报价明细表的小计=人数×周期×单价）
- 日期差自动计算（在场天数=退场-进场）

### C. 需新建的 5 类引擎

| 引擎 | 适用附件数 | 核心能力 | 工作量 |
|------|-----------|---------|--------|
| **段落引擎** | 7 项 | 多段文本 + 占位符替换 + 签署栏 | 2 人天(基础) |
| **章节引擎** | 2 项 | 多级标题 + 正文 + 编制指引 + 目录 | 3 人天(基础) |
| **勾选表引擎** | 3 项 | □/☑ 符号 + 多选项 + 签署栏 | 1.5 人天 |
| **层级图引擎** | 3 项 | 表格模拟组织架构 + 连线 | 3 人天 |
| **柱状图引擎** | 2 项 | 基于甘特扩展，堆叠填色 | 1.5 人天 |

> **结论**：甘特引擎 + 列式引擎两类基类可覆盖 **29/45 = 64%** 的附件；加上小幅扩展可覆盖 **37/45 = 82%**，超过80%目标。

## 四、监理类 vs TIS 类差异化附件

| 维度 | 监理类特有 | TIS类特有 |
|------|-----------|-----------|
| 核心文件 | 总监任命书、监理大纲14章、旁站方案表、见证取样计划 | 独立性承诺函、TIS方案11章、检查节点计划表(7个必检节点) |
| 风险分类 | 7类常见风险，等级=极高/高/中/低 | 三级：严重/重大/一般技术风险 |
| 报告时效 | 按合同约定 | **强制**：不合格12h、合格24h、严重立即+24h |
| 设备差异 | 回弹仪、钢筋扫描仪、全站仪、水准仪 | 内窥镜、X光、红外成像、无人机 |
| 独立性 | 与施工单位无隶属即可 | **极严格**：不得与任何参建方关联或兼任 |
| 整改闭环 | 通知单→整改→复查→闭合 | 通知→方案审核→跟踪→复查→闭环→拒不上报机制 |

## 六、风险提示

| 风险 | 影响 | 缓解措施 |
|------|------|---------|
| 章节引擎工作量大 | 第一阶段延期 | 先做简单版(直接复用 builtin.json 文本)，后续迭代 |
| 层级图跨平台渲染不一致 | Word/WPS显示错位 | 只用表格模拟法，放弃真实形状 |
| 计算列与报价模块冲突 | 数据不一致 | 附件只读展示，权威报价以 pricing.py 为准 |
| 横向19列业绩表打印溢出 | 打印失败 | 自动缩放列宽 + 文档末尾提示确认 |
| □/☑ 符号字体不支持 | 显示乱码 | 统一宋体(已验证支持) |
